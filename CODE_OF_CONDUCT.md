# Código de conduta

Este é um projeto pequeno, mantido por uma pessoa. Não há comitê nem processo formal — o que existe é uma expectativa simples de comportamento, que vale para issues, pull requests, discussões e qualquer outro espaço do projeto.

## O que se espera

- Trate as pessoas com respeito, inclusive quando discordar delas.
- Critique a ideia, o código ou a decisão — não quem escreveu.
- Aceite que "não" é uma resposta possível. O escopo do projeto é decidido pelo mantenedor, e uma proposta recusada não é um julgamento sobre quem propôs.
- Assuma boa-fé. Muita gente aqui não escreve no próprio idioma nativo; leia a intenção antes de reagir ao tom.

## O que não é aceito

Assédio, ataques pessoais, discurso de ódio ou discriminação de qualquer tipo, conteúdo sexual, ameaças, e divulgação de informação privada de outra pessoa sem autorização.

## Se algo acontecer

Relate ao mantenedor abrindo uma issue — ou, se o assunto for sensível, por contato privado através do perfil [@JoaoVictorVM](https://github.com/JoaoVictorVM) no GitHub.

O mantenedor pode editar, ocultar ou remover comentários, commits, issues e pull requests que violem este código, e bloquear quem insistir. Não há processo de recurso: é um projeto pessoal, e a decisão final é de quem o mantém.
